# Security Policy

## Reporting a vulnerability

**Do not open a public issue.** Report vulnerabilities privately through
GitHub: **Security → Report a vulnerability** on this repository, or by email
to **security@tradvia.org**.

Please include the affected version, steps to reproduce and the impact you
expect.

## What to expect

| Step | Target |
|---|---|
| Acknowledgement | 3 business days |
| Initial assessment | 10 business days |
| Fix for critical issues | 30 days |

We coordinate disclosure with the reporter and credit them in the advisory
unless they prefer to stay anonymous.

## Supported versions

Only the latest minor release receives security fixes until version 1.0.
