ConexõesConnections Partial #58

Tela "Conexões" (role admin): provedor e modelo por papel do fluxo (planner/executor/reviewer/orchestrator), e o segredo de cada provedor de IA (chave de API ou o token da assinatura do Claude Code). Hoje só o papel orchestrator (o chat) de fato usa a escolha; os outros papéis ainda leem só a configuração, sem aplicá-la. O chat só funciona com uma IA configurada por chave de API (Anthropic, OpenAI ou Gemini); sem ela, fica desligado e o painel diz o motivo. O token da assinatura do Claude Code serve só ao executor, nunca ao chat. Chave de API é o único método para Anthropic/Gemini/OpenAI — nenhum dos três oferece hoje um login via navegador equivalente ao da assinatura do Claude Code para apps de terceiros (ver ADR 0009).The "Connections" screen (admin role): provider and model per flow role (planner/executor/reviewer/orchestrator), and each AI provider's secret (an API key, or the Claude Code subscription token). Today only the orchestrator role (the chat) actually uses the choice; the other roles still only read the configuration, without applying it. The chat works only with an AI provider configured with an API key (Anthropic, OpenAI or Gemini); without one it is off and the panel says why. The Claude Code subscription token runs the executor only, never the chat. An API key is the only method for Anthropic/Gemini/OpenAI — none of the three currently offers a browser login for third-party apps the way the Claude Code subscription does (see ADR 0009).
